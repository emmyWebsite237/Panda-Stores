Panda Store — Gaming Account Marketplace Landing Page
=======================================================

FILES:
- index.html   → the full landing page (open directly in any browser)

HOW TO USE:
1. Double-click index.html to preview it locally, or upload it to any
   web host (Netlify, Vercel, GitHub Pages, cPanel, etc).
2. Everything (HTML, CSS, JS) is in this single file — no build step needed.
3. Replace the placeholder listings, stats, and reviews with real data
   whenever you're ready — search for "listing-card" and "review-card"
   in index.html to find them.
4. Add more games by copying an existing chip in .games-filter and a
   card in .listing-grid.

CUSTOMIZING:
- Colors live at the top of the <style> block under :root (--bamboo,
  --neon-cyan, --neon-pink, --gold, etc).
- Fonts: "Baloo 2" for headings, "Poppins" for body text, "Space Mono"
  for prices/tags — all loaded from Google Fonts.

Have fun building Panda Store! 🐼🎮
